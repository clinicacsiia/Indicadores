Como ler este painel
  • Etiqueta de cada indicador: Direto = o Klingo entrega o dado pronto · Derivado = cálculo sobre dados que o Klingo entrega · Aproximação = o dado mais próximo que existe, mas não é exatamente o conceito pedido · Sem fonte = nenhum relatório traz o dado (o cartão diz o que falta; não mostro zero para não parecer que está tudo certo).
  • Competência escolhida no topo vale para os indicadores marcados “Competência” (mês de execução das guias e do período das faturas). Os marcados “Posição de hoje” não mudam com o mês; os de glosa são acumulados desde set/2026, porque a glosa chega semanas depois do atendimento.
  • Comparação em cada cartão: “% do produzido” ou “% do faturado” mostra quanto do valor anterior do ciclo já chegou àquela etapa. A variação contra o mês anterior só aparece com os dois meses completos (mês em andamento contra mês cheio seria uma comparação injusta).
  • Guias: o relatório de Guias repete a guia uma vez por procedimento; aqui conto cada guia uma vez.
  • Como a página é organizada: Resumo (os 16 indicadores e o caminho do dinheiro), Análise (guias, pendências e convênios em gráficos) e Detalhes (tabelas, recolhidas: clique para abrir).
  • Atualização: o botão consulta os relatórios de Guias, Glosas e Recursos e Baixas e também os de Faturamento e Financeiro que os indicadores usam. Os dados ficam em Indicadores.xlsx.
